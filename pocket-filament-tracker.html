Pocket Filament Tracker

App Description

This app is intended to help 3D printing hobbyists track their filament spools easily and on-the-go. It tracks how many filament spools and grams are left on each spool. It is an efficient way to quickly check if you need to stock up on any filament while out and about!

Things to Note:

-Pro Version: Export Data prior to removing any models or filaments in the event of accidental removal. They may only be recovered if previously saved.

-Exporting Data will overwrite previously exported data.

-Currently only 4 flaments can be attached to one model, but another model can be added for any additional filaments used.

-For any suggestions on improvements, please leave a review on my Google Play Store App page!
