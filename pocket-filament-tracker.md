<h1>Pocket Filament Tracker</h1>

<div>
  <h2>App Description</h2>
  <p style="text-indent: 20px;">This app is intended to help 3D printing hobbyists track their filament spools easily and on-the-go.  It tracks how many filament spools and grams are left on each spool.  It is an efficient way to quickly check if you need to stock up on any filament while out and about!</p>
</div>

<div>
  <h2>Things to Note:</h2>
  <h3 style="text-indent: 40px;">-Pro Version: Export Data prior to removing any models or filaments in the event of accidental removal.  They may only be recovered if previously saved.</h3>
  <h3 style="text-indent: 40px;">-Exporting Data will overwrite previously exported data.</h3>
  <h3 style="text-indent: 40px;">-Currently only 4 flaments can be attached to one model, but another model can be added for any additional filaments used.</h3>
  <h3 style="text-indent: 40px;">-For any suggestions on improvements, please leave a review on my Google Play Store App page!</h3>
